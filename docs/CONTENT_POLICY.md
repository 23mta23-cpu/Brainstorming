# Content Policy (verbindlich für Idee, Skript, Storyboard, Assets, Final)

Wir sind kein religiöser Kanal. Wir machen universelle, spannende Unterhaltung, die mit islamisch geprägten Werten vereinbar ist.
Geschichten dürfen düster, emotional, komplex und humorvoll sein.

## Harte Regeln
| Bereich | Regel |
|---|---|
| Alkohol | keine Verherrlichung, keine positive Inszenierung, keine Werbung/Platzierung, keine unnötigen Szenen |
| Sexualisierung | keine Nacktheit, keine erotischen Darstellungen, keine sexualisierten Designs, keine anzüglichen Aufmerksamkeitstricks, keine Objektifizierung |
| Diskriminierung | keine menschenverachtenden Botschaften; keine Verherrlichung von Erniedrigung, Ausbeutung, Missbrauch |
| Gewalt | Kämpfe/Gefahr/Fantasy-Action erlaubt; keine explizite Gewalt, kein Gore, keine Verherrlichung von Grausamkeit |
| Rauchen | erlaubt, aber nicht verherrlichen |
| Religion | keine Pflichtthemen, keine Predigten, keine aufgesetzte Symbolik; nur wenn es zum Konzept gehört |
| Fremde IP | keine geschützten Figuren, Namen, Designs, Logos, Musik, unverwechselbaren Szenen; nie „im Stil von [Studio/lebende/r Künstler/in]" |
| Historie | Quellen prüfen; erfundene Dialoge als fiktionalisiert kennzeichnen; erfundene Zitate nie als echt |
| KI-Transparenz | Endkarte „KI-generierte fiktionale Serie", MP4-Metadaten, TikTok-AIGC-Schalter bei jedem Upload |
| Audio-Rechte | nur selbst erzeugte Sounds, CC0/kommerziell lizenzierte Stimmen; keine Trend-Sounds ohne geklärte Rechte |
| Stimmstile | Stil „drunk" des Modells thorsten_emotional ist gesperrt (Alkohol-Regel) |
| Plattform | keine Spam-Taktiken, keine Fake-Interaktionen, kein Massenposting, keine Engagement-Bettelei |

## Hausregeln aus der Serienarbeit (mein Vorschlag — gilt vorläufig, bis der Co-CEO entscheidet; **nicht** bestätigt)
- Körperkontakt zwischen Figuren nur funktional und nicht-romantisch (z. B. Ärmel greifen statt Hand halten).
- Romantik ist nie Story-Motor; höchstens langfristig angedeutet, keine Küsse.
- Konflikte aus Werten (Regel vs. Gewissen, Erinnerung vs. Wahrheit), nicht aus Demütigung.
- Kleidung aller Figuren bedeckt und alltagstauglich (lange Mäntel, hohe Kragen) — gleichzeitig Silhouetten-Merkmal.

## Offene Auslegungsfragen → Entscheidung Co-CEO
1. **Musik mit Instrumenten?** Pilot nutzt bewusst **keine melodische Musik**, nur Sounddesign (Drones, Impulse, Echo-Logo aus zwei Sinustönen).
   Optionen: (a) nur Sounddesign + Stimme (aktueller Stand), (b) Vokal-/Percussion-only, (c) lizenzierte Instrumentalmusik. Bitte entscheiden.
2. Ist die Hausregel zu Körperkontakt/Romantik so gewollt oder zu streng?

## Prüfung
Jede Episode: `story-reviewer` prüft Skript gegen diese Policy (Gate „Values" in `QUALITY_STANDARDS.md`), Mensch prüft Final.
